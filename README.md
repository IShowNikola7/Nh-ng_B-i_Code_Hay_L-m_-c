# Những Bài Code Hay (C/C++ C-style)

Kho lưu trữ bài tập rèn tư duy thuật toán, chia hàm nhỏ và tổ chức mã nguồn theo lộ trình **Nền tảng C-style trước, Thư viện có sẵn sau**.

---

## 1. Cấu trúc thư mục & Chuyên đề

- `utils/` : Thư viện hàm dùng chung toàn dự án (`swap`, làm tròn số, nhập/xuất cơ bản...).
- `01_mang_1_chieu/` : Kỹ thuật hai chỉ số, mảng tần suất, xóa/chèn phần tử, mô phỏng ngăn xếp bằng mảng tĩnh.
- `02_mang_2_chieu/` : Nhập/xuất ma trận, sắp xếp hàng/cột, hoán vị, chuyển vị, xoay ma trận.
- `03_chuoi_ky_tu/` : Xử lý chuỗi C-style (`char[]` kết thúc bằng `'\0'`), kỹ thuật cờ trạng thái, tách từ.
- `04_struct/` : Thiết kế kiểu dữ liệu cấu trúc (`struct`), truyền tham chiếu hằng `const &`, tìm kiếm và sắp xếp đối tượng.
- `05_doc_ghi_file/` : Đọc/ghi tệp văn bản (`ifstream`/`ofstream`), xử lý trôi lệnh, tách dữ liệu theo định dạng.
- `06_con_tro_cap_phat_dong/` : Con trỏ, mảng động, chuỗi động, cấp phát và giải phóng bộ nhớ `new`/`delete`.
- `baitoangemini/` : Thư mục tổng hợp tự do, chứa các bài tập LeetCode, giải thuật đa dạng, bài code luyện tập hằng ngày hoặc các bài tập tổng hợp không giới hạn chuyên đề.
